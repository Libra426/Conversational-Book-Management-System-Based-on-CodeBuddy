# Project Brief：图书管理系统

## 1. 项目背景

本项目是《软件设计与体系结构》课程实验项目，用于训练需求分析、UML 建模、架构设计、数据库设计、详细设计和代码实现能力，并实践 AI 编码 Agent 辅助下的 Spec-Driven 开发流程。

## 2. 项目目标

开发一个图书管理系统，支持读者注册、借阅证管理、图书借阅、图书归还、借阅查询、图书预约、系统维护和超期罚款。

## 3. 目标用户

- 读者（Reader）
- 学生读者（Student，专科生 / 本科生 / 研究生 / 博士生）
- 教师读者（Teacher）
- 图书管理员（Librarian）
- 系统管理员（SystemAdmin）

## 4. 主要业务

- 注册账号
- 办理借阅证
- 借阅图书
- 归还图书
- 查询借阅信息
- 预约图书
- 维护图书标题信息
- 维护馆藏副本
- 维护管理员
- 计算超期罚款

## 5. 读者类型与借阅规则

| 读者类型 | 最大借阅数量 | 借阅期限 |
|---|---|---|
| 专科生 JUNIOR_COLLEGE | 3 本 | 30 天 |
| 本科生 UNDERGRADUATE | 5 本 | 30 天 |
| 研究生 GRADUATE | 10 本 | 60 天 |
| 博士生 DOCTOR | 15 本 | 90 天 |
| 教师 TEACHER | 20 本 | 90 天 |

## 6. 借出物类型与罚款规则

| 借出物类型 | 超期罚款（元/天） |
|---|---|
| 中文图书 CHINESE_BOOK | 0.10 |
| 外文图书 FOREIGN_BOOK | 0.20 |
| 中文杂志 CHINESE_MAGAZINE | 0.05 |
| 外文杂志 FOREIGN_MAGAZINE | 0.10 |
| 论文 THESIS | 0.50 |

## 7. 技术要求

- 使用 UML 表达分析和设计结果（PlantUML 文本格式）。
- 使用分层架构和 MVC 模式。
- 使用 Agent 辅助生成规格、UML、设计和代码。
- 所有 Agent 生成内容必须人工审查。
- 最终需要有可以运行的代码和自动化测试。
- 技术栈：Python 3.13 + FastAPI + SQLAlchemy + SQLite + Pydantic + pytest。

## 8. 暂不实现

- 支付系统真实扣款
- 图书条码扫描硬件
- 复杂全文检索
- 多校区馆藏调拨
- 微信或统一身份认证登录
