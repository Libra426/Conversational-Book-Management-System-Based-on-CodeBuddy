# 测试计划

## 1. 测试策略

- 单元测试：策略层（BorrowPolicy、FineRule）纯逻辑。
- 集成测试：通过 TestClient + 内存 SQLite 覆盖 API 全链路与权限。

## 2. 测试用例

| 编号 | 目标 | 类型 | 输入 | 预期结果 |
|---|---|---|---|---|
| TC-001 | 注册读者成功 | 集成 | 合法读者字段 | 201 返回 id |
| TC-002 | 办理借阅证成功 | 集成 | 已存在 reader_id | 201 card_no 唯一 |
| TC-003 | 借阅证无效借书失败 | 集成 | 不存在 card_no | 403 |
| TC-004 | 借书成功 | 集成 | 有效 card_no + 可借 barcode | 201 Loan BORROWED |
| TC-005 | 超数量借书失败 | 集成 | 已借满的读者 | 409 超出借阅数量 |
| TC-006 | 有超期未还借书失败 | 集成 | 有超期 Loan 的读者 | 409 存在超期未还 |
